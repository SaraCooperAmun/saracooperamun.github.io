### Overview

During my return to **PAL Robotics (2024–2025)**, I worked as a research engineer on the development of the **TIAGo Head**, a tabletop social robot platform for human–robot interaction research and deployment.

In collaboration with the Human–Robot Interaction team, I contributed to early system integration and prototype development, focusing on:
- extending ROS4HRI-based social perception pipelines  
- integrating multimodal dialogue systems (ASR, TTS, LLMs)  
- supporting real-time conversational interaction  
- improving perception–action coupling for social behaviour  

Related publication presented at RO-MAN 2025:
["TIAGo Head: an AI Powered Platform for Social Robotics"](/publication/2025-08-tiago-head)

### Platform description

TIAGo Head is a tabletop social robot designed for interactive scenarios such as reception desks, museums, and public-facing information points. It combines:
- expressive robotic head for social cues  
- RGB-D vision and audio perception  
- ROS2-based modular architecture  
- unified human representation via ROS4HRI  
- speech recognition, synthesis, and dialogue systems  
- optional LLM-based conversational reasoning

### System architecture

![TIAGo Head software architecture](/images/tiago_head_amor.png){: width="500px" }

The architecture is structured around a modular pipeline that connects perception, dialogue, reasoning, and behavior generation:

- **Perception layer:** processes audio-visual input (faces, speech, attention, identity tracking) using ROS4HRI-compatible modules  
- **Dialogue layer:** combines classical chatbot pipelines (e.g., Rasa) with LLM-based conversation modules for flexible interaction  
- **Knowledge & reasoning layer:** maintains structured context and supports grounding of user requests in a persistent representation of the environment  
- **Behavior layer:** coordinates gaze, speech, and head motion through skill-based execution and a mission controller  
- **Expressivity layer:** ensures coherent multimodal social signals (speech, facial expression, motion)

### Demonstration use-case: Receptionist scenario

A representative use-case implemented on TIAGo Head is a **receptionist-style interaction system** deployed in a public-facing environment.

In this scenario, the robot acts as an interactive receptionist that:
- detects approaching users and initiates engagement using gaze and head orientation  
- identifies and tracks users during interaction using real-time perception modules  
- engages in natural conversation through a hybrid dialogue system (rule-based + LLM-based responses)  
- provides contextual information such as news updates, event information, or general assistance  
- adapts responses based on conversational context and perceived user intent  

The interaction is designed to be continuous and socially aware, combining perception, dialogue, and behaviour generation into a single closed loop.
